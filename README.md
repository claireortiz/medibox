# MediBox

## 📷 Preview 

![mediboxschematic.jpg](mediboxschematic.jpg) 

# MediBox is a smart medicine management system designed to help users organize and manage their medications efficiently. It aims to promote proper medication adherence by providing scheduled reminders and a convenient way to monitor medication intake. The prototype demonstrates the system's design, components, and functionality, offering a practical solution for improving medication management and helping users maintain a consistent medication routine.
